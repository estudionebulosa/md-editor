🎯 Características del Explorador de Archivos

El editor incluye un explorador de archivos interoperable que se comunica mediante eventos personalizados.

Modos de almacenamiento disponibles:

  • local - Almacenamiento en localStorage del navegador (por defecto)
  • github - Sincronización con repositorio de GitHub (requiere token)
  • hybrid - Combinación de ambos (GitHub + fallback local)

⚙️ Configuración

💡 Para usar GitHub API, necesitas un Personal Access Token con permisos repo.

Estado: Listo. Haz clic en 📁 para abrir el explorador de archivos.
